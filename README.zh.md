# dsh-token-heatmap

中文 | [English](README.md)

在 DSH **设置**中增加一节「Token 用量」：每日 token 消耗热力图，一格一天，以主题灰阶表示当日相对用量。

选中日期后，详情中同时显示**以人民币估算的当日消费金额**，按 DeepSeek 官方价目表与峰谷时段计算。

数据全部来自本机 DSH 会话日志，**不向外部服务发送请求，也无需另行记录用量**。

> **隐私**：本插件不发起任何外部请求。会话日志仅在本机读取，聚合结果仅提供给本机 DSH 页面。
> 仓库中不包含任何个人数据或凭据。

## 设计要点

- **原生设置区块，而非浮层组件**。组件注册至 `settings.section` 槽位，仅渲染 React 元素；不向 `document.body` 追加节点、不替换应用根节点、不引用任何 Harness Client 包。因此它与内置设置项并列于侧边栏，而不是覆盖在应用之上。详见[实现要点](#实现要点)。
- **仅使用本地数据，单一来源**。数据不离开本机，也无需额外维护账本：所有数字均来自 DSH 自身写入的会话日志。
- **显式解析会话日志格式**。多帧拼接的 zstd、回放导致的重复 `seq`、写入过程中的截断尾帧，三者均作为独立情况处理。单次解压只能获取多帧日志的第一帧，会导致用量统计偏低。详见[数据来源](#数据来源)。
- **色阶在量级两端均可读**。四种口径之间相差数个数量级，因此色阶取自**本地数据的分位数**（25/50/75 百分位），而非固定阈值。缓存读取通常占当日用量的绝大部分（下方截图中为 99%），这也是提供「输入+输出」这一独立口径的原因。
- **亮度仅用于有记录的日子**。无用量记录的日期固定处于最低视觉层级，因此空白网格在视觉上保持中性，有记录的日期可清晰辨识。这一点同时具备可访问性上的好处：该编码不依赖色相。
- **金额为估算，而非账单**。DSH 会话日志只记录 token 数量，不含金额，因此详情页按 DeepSeek 官方人民币价目表，对当日输入、缓存读取与输出 token 分别计价；峰谷时段按每条记录自身的时间戳判定，并在界面上明确标注为估算。详见[金额估算](#金额估算)。
- **选中与展开为相互独立的状态**。收起当日详情后，选中外圈仍保留在热力图上；选择其他日期时详情直接切换；按 `Esc` 先收起、再次按下才取消选中。因此连续查看多天不需要任何中间的关闭操作。
- **主题与语言均与宿主集成**。颜色取自宿主主题 token（`--dsw-alias-*`），全部可见文案通过 `ctx.locale.register` 注册，宿主切换语言时本节随之重新渲染；数字单位同样本地化（中文 `万`/`亿`，英文 `K`/`M`/`B`）。
- **以回归测试替代声明**。五个自检入口覆盖分帧解析、去重、缓存、自然周边界、客户端渲染与路由注册。详见[结构](#结构)。

## 功能

- 默认近半年（26 周）；可切换近一年，全年分为上下两排（27 + 26 周），各排带月份刻度
- 格子上限 20px、间距 4px，按容器宽度适配，避免横向滚动条
- **每天 / 每周**：每日独立色阶，或同一自然周整列同色；周日到周六排列，未来日期留空
- **四种口径**：总量 / 输入+输出 / 缓存读 / 输出；使用主题灰阶表示相对高低
- 悬浮或聚焦显示对应日期、当前口径的 Token 数量和「点击查看详情」；周视图标注本周数量
- 选择日期后，在热力图下方就地显示当日总量、输入、输出、缓存读取、调用次数、非零缓存写入，以及以人民币估算的消费金额；周视图中的格子仍对应所选日期
- 再次选择已选日期仅收起详情正文并保留选中外圈；收起行内提供展开控件，`Esc` 亦可用于收起，选择其他日期无需先收起即可切换
- **金额估算**：按 DeepSeek 官方人民币价目表计价，峰谷时段按每条记录的时间戳判定；未知模型回退到 Flash 价目并在界面标注
- Token 构成条按实际数量展示各分项及比例；没有用量时显示空状态
- 首次加载斜向铺开约 600ms，顶部统计不等待动画；切换口径、范围或选择日期不重播
- 原生按钮支持 Enter/Space，保留焦点反馈；尊重系统减少动态效果设置
- 摘要显示今日 / 本周 / 全部历史合计；每分钟刷新，窗口重新可见或聚焦时重新请求
- 中英文文案、月份、数字单位跟随宿主语言，深浅主题跟随宿主

## 数据来源

`<DSH_HOME>/sessions/<项目>/<会话>/session.v*.jsonl.zstd`

插件读取包含有效时间戳和 `data.usage` 的日志记录：

```
inputTokens / outputTokens / cacheReadTokens / cacheWriteTokens / totalTokens
```

外加 `time`（epoch 毫秒）与 `data.message.source.model`，按本地日历日聚合即得每日用量。

三个必须处理好的细节：

1. **日志包含多个 zstd 帧** —— 当前解析器依据帧魔数划分并分别解压，以保留可读取的帧。
2. **同一 `seq` 可能重复出现**（回放）—— 按 seq 去重，避免重复计数。
3. **会话写入中尾部可能出现截断帧** —— 只跳过那一帧，不要丢掉整个文件。

宿主侧按文件大小、修改时间和统计时区缓存解析结果，仅重新解析新增、修改或统计时区发生变化的文件。

### 关于口径

「总量」包含日志报告的缓存读取，缓存占比随使用情况变化。「输入+输出」仅统计这两项。DSH 日志只记录 token 数量、不含金额，因此详情中的金额是本插件按官方价目表计算的估算值。

颜色分级用**分位数**（非零用量的 25/50/75 分位），不是绝对阈值，所以切换口径时量级差几十倍，热力图依然有可读的层次。

### 金额估算

由于 DeepSeek 的单价随时段变化，金额按**每条会话日志记录**分别计算：

```
金额 = 缓存读取 token / 1e6 × 缓存命中价
     + 输入 token     / 1e6 × 缓存未命中价
     + 输出 token     / 1e6 × 输出价
```

- 单价单位为人民币元 / 百万 token。`deepseek-flash` 为空闲 0.02 / 1 / 4、高峰 0.04 / 2 / 8；`deepseek-v4-pro` 为空闲 0.15 / 4.5 / 13.5、高峰 0.3 / 9 / 27。
- 高峰时段为北京时间工作日 09:00–12:00 与 14:00–18:00；周末与中国法定节假日全天按空闲时段计价。
- 未列入价目表的模型回退到 Flash 价格，详情中会列出这些模型，使假设可见。
- 该金额为估算值，不是账单；实际金额以提供方计费记录为准。

价目表与 2026 年节假日清单位于 `lib/pricing.js`；DeepSeek 调整价格、或国务院公布次年放假安排后需要更新。

## 安装

桌面应用的 profile 由应用独占管理，`dsh plugin` 命令会拒绝改它，所以要在应用里装：

1. 打开 DSH → 侧栏 **插件** → **添加插件**
2. 填入本目录的绝对路径（命令行形式是 `dsh plugin add "link:<路径>"`）
3. 安装后重启应用
4. 进 **设置**，导航里会多出「Token 用量」

卸载：同一页面的组合包卡片 → 卸载。

## 实现要点

**通过宿主扩展槽注册界面。** 组件注册进 `settings.section`，只渲染 React 元素；
不直接导入 Harness Client 包，样式优先使用宿主主题变量。
（DSH 插件规范明确禁止往 `document.body` 追加元素或替换应用根节点。）

**自适应尺寸。** `ResizeObserver` 量容器宽度，算出每格边长写进 CSS 变量 `--dth-cell`：
半年按 26 列适配，全年按每排最多 27 列适配；格子上限 20px，计算时扣除间距和内边距。

**周对齐。** 从当前周的周日向前倒推 25 周或 52 周，因此每列都是完整自然周；今天之后的格子留空。
月份刻度贴在"包含该月 1 号"的那一列，并为每排起始列补充月份标签。

**本地化。** 界面文案通过翻译字典管理：插件用 `ctx.locale.register(ns, { zh, en })` 注册自己的命名空间字典，
再通过框架提供的翻译函数读取，所以切语言时这一节会重渲染。数字单位也跟着走（中文 `万/亿`，英文 `K/M/B`）。

客户端测试直接执行 `client.js`，使用 React 钩子桩覆盖首次可见帧、精简 Tooltip、页内详情、范围切换和构成条；不替代真实 DSH 中的布局、动画、焦点与主题验收。
